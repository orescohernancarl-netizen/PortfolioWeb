My Journey

From writing my first lines of code to building full web applications, every project, mistake, and late-night debugging session has been part of the journey.

First Year

Where It All Started

My journey into Information Technology started with the basics. At first, programming felt confusing and unfamiliar. I started learning the fundamentals of programming, logic, algorithms, HTML, CSS, and JavaScript.

There were plenty of errors, confusing syntax, and moments where I had no idea why my code was not working. But every project slowly made programming easier to understand.

Programming Foundation

Learning Python

Python became one of the languages that helped me understand programming more deeply. I worked with variables, conditions, loops, functions, file handling, and problem-solving.

This was one of the stages where programming started making more sense instead of just memorizing code.

Web Development

From HTML & CSS to JavaScript

I started turning my programming knowledge into actual websites using HTML and CSS, then added JavaScript to make them interactive.

This was where I started enjoying web development and experimenting with layouts, responsive design, animations, and interactive features.

Backend Development

Node.js, Express & APIs

I eventually moved into backend development and started learning how servers and web applications actually work. I worked with HTTP, the filesystem, Express, routes, static files, and APIs.

This was the point where I started understanding that websites are more than just what appears on the screen.

Modern Front-End

React & Vite

My learning continued into React and Vite, where I began working with components, JSX, imports, and modern front-end development.

One of the projects I worked on was a Sticky Notes application, which helped me understand how React applications are structured.

Version Control

Git & GitHub

I also learned how to use Git and GitHub to manage my projects, create commits, push changes, pull updates, and work with repositories.

And of course, learning Git also came with the legendary merge conflicts. 😂 Solving those problems became another part of the learning process.

Now

BSIT Journey Continues

From the first year when programming felt completely new to working with JavaScript, Node.js, Express, React, Git, and databases, the journey has been about learning one step at a time.
